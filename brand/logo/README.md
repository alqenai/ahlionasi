# Shorbaka logo: «خيطين» (two threads)

The word شرباكة with two threads woven through it: a teal one for family, a coral one for friends.
They run behind the letters, come over them in a few spots, and cross each other.

- `svg/`: wordmark, stacked logo (with SHORBAKA), English horizontal logo, mark, app icons. Text is outlined, no font needed. Gaps are real cut-outs, so every file works on any background.
- `png/`: the same at large sizes, transparent, plus app icons and the Instagram profile picture.
- `source/`: how they are made. `outline.py` turns Readex Pro 700/500 into paths (needs uharfbuzz + fonttools and the font files), `kit.js` builds every SVG, `export.js` renders PNGs with Playwright, `post.py` makes the favicon and small icons.

Colours: navy #0E2A47, pearl #F4EFE6, teal #2EC4B6 (#1A9E92 on light), coral #FF8A80 (#F0675C on light), sand #E9C46A (#B98E2E on light).
